# Tickets de BEBIDA (fotos)

Guarda aquí las fotos de tickets de bebida. Nombre sugerido: `proveedor-AAAA-MM-DD.jpg`
(ej. `alcampo-2026-08-20.jpg`). Si un ticket mezcla categorías, guarda la foto una sola
vez (aquí o en la categoría que más pese) y reparte las líneas en los JSON de `../../`.

Datos normalizados: `../../tickets-bebida.json`.
