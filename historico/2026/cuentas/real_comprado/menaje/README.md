# Tickets de MENAJE (fotos)

Guarda aquí las fotos de tickets de menaje: vasos, platos, cubiertos, servilletas,
hielo, bolsas, papel, desechables, etc. Nombre sugerido: `proveedor-AAAA-MM-DD.jpg`.
Si un ticket mezcla categorías, guarda la foto una sola vez y reparte las líneas en
los JSON de `../../`.

Datos normalizados: `../../tickets-menaje.json`.
