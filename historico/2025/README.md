# Histórico 2025

Esta carpeta guarda la información de gastos, ingresos y sobrantes del año 2025.

## Archivos

- `index.html`: vista consultable desde la web
- `gastos-2025.json`: datos con precios y totales
- `sobrantes-2025-resumen.md`: resumen de sobrantes del evento

## Uso

Se usa como referencia para comparar compras y ajustar mejor la planificación del año siguiente.
