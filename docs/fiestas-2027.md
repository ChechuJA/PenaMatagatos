# Fiestas 2027 · mirando al futuro

> Esta es la hoja de ruta operativa para 2027, basada en las dos últimas ediciones y en la realidad del censo y del consumo.

## 1) Base realista

- **Censo oficial:** 30 miembros de la peña.
- **Asistencia real 2026:** 29 personas y 101 persona-días.
- **Referencia 2025:** también se trató de un verano con consumo alto, pero con esa base de 2026 ya se puede afinar mejor.
- **Regla de trabajo:** no comprar para “30 personas todos los días”; comprar para un escenario realista y dejar margen por si sube la asistencia.

### Escenarios

| Escenario | Persona-días aprox. | Lectura |
|---|---:|---|
| Conservador | 110-120 | se parece a una edición normal |
| Realista | 120-130 | mejor base para 2027 |
| Máximo | 140-150 | si casi todo el mundo va casi todos los días |

**Conclusión práctica:** para 2027 el punto de partida más útil está entre **120 y 130 persona-días**.

## 2) Qué cambia respecto a 2026

- 2026 fue una edición muy buena para calibrar el consumo real.
- El mayor patrón fue un consumo muy concentrado en **viernes y sábado**.
- La bebida que más se movió fue la cerveza, con un buen volumen de 0,0, Coca-Cola Zero y refrescos.
- Los sobrantes de 2026 también ayudan: no hace falta repetir exactamente el mismo stock, pero sí dejar margen para los productos que más se consumen.

## 3) Estimación de compra para 2027

### Base recomendada

| Producto | Estimación 2027 |
|---|---:|
| Cerveza normal | 160-200 unidades |
| Cerveza 0,0 | 35-45 unidades |
| Coca-Cola Zero | 30-40 unidades |
| Coca-Cola original | 10-15 unidades |
| Agua | 60-75 botellas |
| Aquarius / refrescos | 20-30 unidades |
| Mezcladores y limón | 20-30 unidades |
| Ginebra y mezclas | 10-15 botellas |
| Ron / whisky / licores | 8-12 botellas |
| Hielo | 10-15 bolsas |
| Menaje / vasos / platos | margen de seguridad para 2027 |

### Regla simple

- Si 2027 se parece a 2026: **compra base entre 120 y 130 persona-días**.
- Si casi todos aparecen a casi todos los días: **subir 15-20%**.
- Si hay dudas, mejor dejar margen para **Coca-Cola Zero, cerveza y agua** antes que quedarse corto.

## 4) Los puntos críticos para no quedarse corto

- **Coca-Cola Zero y Sprite**: fueron los puntos más sensibles del último año.
- **Cerveza normal y 0,0**: siguen siendo la base del consumo.
- **Agua**: conviene tener más de la que parece necesaria.
- **Ginebra y mezcladores**: si se mueve mucho por la noche, puede agotarse antes de lo esperado.

## 5) Cómo encajar esto con la peña

Si se hace una estimación útil para la organización, la mejor forma es esta:

1. Empezar con **120-130 persona-días** como referencia. 
2. No comprar “para 30 personas todos los días”.
3. Mantener un margen para los días de mayor consumo.
4. Usar los sobrantes de 2026 como primer filtro antes de reponer productos.
5. Registrar consumo por día para ajustar 2028 con datos todavía más exactos.

## 6) Resumen rápido

- **30 miembros oficiales** = base máxima del censo.
- **2026 = 101 persona-días** = referencia real.
- **2027 = 120-130 persona-días** = escenario más sensato.
- **Compra recomendada:** conservadora, con margen en cerveza, Coca-Cola Zero, agua y refrescos.
- **Lo más importante:** no gastar todo el presupuesto en la compra inicial; dejar un colchón para que no falte lo esencial.
